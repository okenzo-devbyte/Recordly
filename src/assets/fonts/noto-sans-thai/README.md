# Noto Sans Thai

Unmodified Noto Sans Thai variable TrueType font, produced and maintained by the Noto Project Authors.
Bundled locally for Thai UI text and Thai caption fallback; no font service is contacted at runtime.

- Official project: https://github.com/notofonts/thai
- Distribution: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosansthai)
- Original filename: `NotoSansThai[wdth,wght].ttf`
- Local filename: `NotoSansThai-Variable.ttf`
- Size: 218,652 bytes
- SHA-256: `5a1c559bb539583c8a1fd99d1c5b9491e5e14478c9cd2bd0970d5c3096cc9ef8`
- Axes: width and weight (100–900).
- Script coverage: Thai and Basic Latin punctuation/compatibility glyphs; matched via Thai `unicode-range` for UI typography and used as Thai script fallback for captions.
